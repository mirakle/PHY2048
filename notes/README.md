# PHY2048 interactive lecture notes

Self-contained HTML pages: notes, simulations and practice questions. Open `index.html` in any modern browser, or serve the folder with GitHub Pages.

| Folder | Topic | Pages |
|---|---|---|
| `1d-kinematics/` | One-dimensional kinematics | Start here, constant velocity, constant acceleration, variable acceleration |
| `motion-in-a-plane/` | Motion in a plane | Start here, vectors, projectile motion, circular motion, relative motion (with optional relativity section) |

Each page view has its own link, for example `index.html#part2` (1-D) or `index.html#projectiles` (2-D).

Notes:
- Equations are rendered by MathJax and the type by Google Fonts, both loaded from CDNs, so an internet connection is needed.
- Built to WCAG 2.1 AA: keyboard-operable simulations, text descriptions for every graphic, light and dark themes.
